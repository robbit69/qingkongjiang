# 请空降｜视频口播跳转

根据视频自带的 CC 字幕定位口播推广，并用字幕时间戳跳转的浏览器扩展。目前支持 B 站视频页。优先用 [Jev](https://docs.typesafe.ai/api) 判断区间；接口失败或结果不稳时，可配置 OpenAI 兼容的 LLM 接口兜底。

## 判定方式

每 254 条字幕作为一个阶段。每阶段只发起一次 Jev 请求，同时判断有没有口播、阶段首尾是否属于口播、第一段口播的起止句，以及是否还有另一段独立口播。若同一段口播跨阶段，按首尾状态拼接；若同阶段有多段独立口播，继续按阶段拆分。边界概率不稳或跨阶段时，再针对两个边界补问一次起止句，不逐句判定。没有广告的阶段会忽略选择题被迫给出的字幕编号。

只有广告存在概率达到设置阈值、边界概率也足够稳定的 Jev 区间才会自动跳过。边界补问失败时仍显示候选区间，供手动核对；LLM 兜底结果也需手动确认。更新到 0.5.0 后，旧版本地分析缓存会重新判定。

## 安装

```bash
npm install
npm run build
```

在 Chrome 或 Edge 的扩展管理页开启开发者模式，加载解压缩的 `dist` 目录。点击扩展图标，在设置页填写 Jev API Key，并用“一键测试连接”检查接口。打开 B 站视频后，鼠标移入播放器，右上角会出现“自动跳过”“UP 免检测”和“重新判断”。“重新判断”会绕过本地分析缓存。默认只自动跳过已手动确认的区间与达到 Jev 置信度阈值的区间；LLM 的候选区间需要先手动确认。

视频进度条下方用绿色、橙色、蓝色分别标出 Jev、LLM、手动区间。自动跳过后，若手动拖回该区间，本次观看不会重复跳过。页面右侧“调试”可查看候选区间、修改起止秒数、手动添加或删除区间，以及历次检测的耗时、接口用量与成本，并直接打开扩展设置。

## 设置

- 顶部显示跳转状态、区间、字幕轨与广告判定用时；用时会根据实际响应时长显示为毫秒或秒加毫秒。
- 可分别切换自动跳过和本地分析缓存。当前视频的 CC 字幕可在设置页一键复制到剪贴板，文本保留每条字幕的时间戳。
- “当前 UP”区域显示其名单状态，并可展开管理名单。名单内 UP 仍可复制 CC 字幕，但不进行广告分析，也不写入分析缓存；名单状态变化会使这个 UP 的旧分析缓存失效，移出后强制重新判断。
- Jev Host、API Key 与可选 LLM 接口在设置页填写，保存后可一键测试通断。自定义 Host 需要授予对应网站的访问权限。LLM 端点应兼容 Chat Completions API。
- 调试面板保留最近 50 次实际分析记录，可展开查看每次请求的耗时与输入／输出 token。Jev 成本按 [TypeSafe 公布的输入单价](https://typesafe.ai/blog/introducing-system-one-models-and-jev)（$0.042／百万 token，输出免费）估算；LLM 成本按设置中的输入／输出单价估算。接口未返回 token 用量或 LLM 未设单价时会明确标记未计价。

## 数据与限制

- 不做语音转写，也没有云端缓存。字幕只发送给已配置的 Jev 或 LLM 接口。
- API Key、设置、白名单、检测历史与手动区间保存在浏览器本地 `chrome.storage.local`。启用分析缓存时，结果按视频分 P 和字幕内容区分，30 天内可复用；命中缓存不会新增接口检测记录。
- 视频需提供可获取的 CC 字幕才能自动分析或复制字幕。没有字幕时仍可手动标记区间。登录 B 站后通常能读取更多字幕轨。
- 接口判断可能有误差；跨阶段的长口播及同阶段多段口播尤其应在“调试”里核对区间。
